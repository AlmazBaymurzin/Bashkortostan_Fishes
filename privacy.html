🔒 Политика конфиденциальности

1. Общие положения

Настоящая Политика конфиденциальности регулирует сбор, использование и защиту персональных данных пользователей сайта www.bashrybka.ru

2. Какие данные собираются

Сайт собирает только статистические данные через Яндекс.Метрику:

  • IP-адрес
  • Тип браузера
  • Страницы посещения

Личные данные (имя, телефон, email) НЕ СОБИРАЮТСЯ.

3. Использование данных

Данные используются только для улучшения работы сайта и анализа посещаемости.

4. Защита данных

Все данные защищены и не передаются третьим лицам.

5. Согласие

Используя сайт, вы соглашаетесь с настоящей Политикой конфиденциальности.
